## Demo & Snippets

## Requirements / Purpose

**MVP**

Book Market is a book trade platform.

- Post a book you've read
- Browse books posted by other users
- Create a trade by offering one of your book and select the book you want in exchange
- When you receive a trade, you can accept or deny, but you can also make a counter offer

- The Book entity, the User entity and the Trade entity each must be able to perform CRUD actions as well

**Purpose of project**

This project's aim is to familiarise myself further with AWS cloud services (hosting and storage)  and Redux, which I've used once prior to this. 

I also aim to strengthen my ability to structure and implement business logic.

**Stack** 

Backend: Java, Spring Boot, Spring Security, Paul Schwarz (dotenv), Maven, Mockito, Junit/Juniper
Frontend: React/Redux, Typescript, AWS

## Build Steps

This project has a DataLoader, which seeds the database and provide 4 users with 4 books each.
After cloning the repo on your computer, simply create and link a database and start your server!

## Design Goals / Approach

I love reading and the completionist in me loves tracking my data day to day, including the books I read! I do this using the popular website Goodreads.

I've drawn inspiration from the website and general feel, thinking of this project as an extension of what Goodreads could offer.
